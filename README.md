# UPI-Fraud-Detection-System
Used for detecting fraud upi transactions
A machine learning–based fraud detection system designed to identify suspicious UPI (Unified Payments Interface) transactions in real time. This project helps simulate how digital payment platforms can reduce financial fraud using data science.

With the rapid growth of UPI payments, fraud cases like unauthorized transfers, phishing, and fake merchant requests are also increasing. This project builds a classification model that predicts whether a transaction is legitimate or fraudulent based on transaction behavior patterns.

The system uses historical transaction data, feature engineering, and supervised machine learning algorithms to detect anomalies.

Objectives

Detect fraudulent UPI transactions with high accuracy

Reduce false positives (so genuine users are not blocked)

Build a scalable ML pipeline for real-time fraud detection

Demonstrate practical use of ML in fintech security
